## Executed result

- **20/20 Python unit tests PASS**
- **10/10 training**, **8/8 held-out** synthetic growth histories classified correctly.
- Browser viewer syntax PASS, ZIP integrity PASS, **5/5 SHA256 file digests PASS**.
- Bounded hypothesis language: conjunction of four predicates, each threshold derived from positive training examples; not selection from a fixed list of complete settlement rules.

- The baseline all-accept rule scored only 3/8 held-out examples.

## Preserved first adversarial failure

```text
INPUT: quiet=3, coverage=90, root-labels=3, conflicts=0
LEARNED RULE: READY
OUTSIDE LABEL: NOT READY
WHY: three labels descended from the same original source
RESULT: -1 PROVENANCE_ANCESTRY_NOT_MODELED
```

The learner's features do not encode independent source ancestry, so the same numeric inputs can have different settlement labels. This exposes a missing **feature**, not an issue fixable merely by adjusting numeric thresholds. The first failure remains preserved and is not trained away. No actual settlement or memory write occurs.

## Honest interpretation

This is supervised learning over synthetic labeled cases with a **programmed** predicate grammar, feature set, training labels and learner. It neither proves Jane invented the concept of stability nor operates as a persistent network of autonomous scouts. Passing the rule predicts readiness under the toy target only; a receipt and separate Jane approval would still be required.
