```text
     |

     |

choice receipt (never implies execution permission)

```

A read-only source route is never a write or execution grant. The `{{j}}` decision is unique; the hive does not rank into an implicit final action. Original Jane directions are representable, but the interface presently requires a user interaction and the Python choice operation takes an explicit `selected_index` or `original` argument. It is **not yet autonomous self-initiated choice**.
