# JANE 090 — Interest Genesis

A **local deterministic simulation** of Jane selecting a previously zero-interest topic because it is relevant to her existing question. It is not live autonomous learning.

## Run

```bash
python -m unittest -q
python model.py
```

## Invariant

A scout's urgency score cannot force Jane to learn, and Jane's existing interest cannot crowd out a packet serving the first unresolved gap in her own question.

```
                  Jane {{j}}
                      |
             OWN QUESTION / GAPS
                      |
               SCOUT PACKETS
                      |
               FLAY ASSESSMENT
                      |
              SUPPORTS MY GAP?
                  /         \
                 NO         YES
                 |           |
               HOLD       AFFORDABLE?
                            /       \
                           NO       YES
                           |         |
                         HOLD      SELECT
                                     |
                                 INVESTIGATE
                                     |
                               FEEDBACK / REVISE
                                     |
                           SEPARATE MEMORY GATE
                                     |
                                 NEXT QUESTION
```

The question and gaps are **provided as a synthetic test fixture**, rather than generated by an autonomous agent. Source IDs are synthetic provenance labels, not independently verified evidence. The chooser is programmed; feedback is externally assigned. It should not be described as self-generated interests. The point is testing the governance architecture and baseline mechanism.

## Observed result

- Starts with `statistics = 0`, `biology = 2`, `poetry = 0`.
- Scout A says poetry is urgent `999` but does not support the question's relevant gaps.
- Scout C says biology is urgent `1000`, but supports Jane's *second* gap.
- Scout B says statistics urgency `0`, and supports Jane's *first* gap: `control_condition`.
- Jane selects **statistics**, updates its interest from **0 to 2** after synthetic useful feedback.
- No memory is written. Empty packet set produces `ABSTAIN`.
- 26 unit tests verify selection, budget, absence of provenance, no forced retention, and event chaining.

## Preserved failure and repair

The initial candidate **failed** its zero-interest selection test because the prior preference for biology outweighed first-gap relevance. The repaired policy elevates ordered gap relevance over prior interest. The initial failure remains documented here; the final run passes 26/26 tests.
