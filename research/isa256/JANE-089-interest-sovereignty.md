# JANE 089 — Interest Sovereignty (2026-11-09)

## Canonical invariant
**Agents submit information packets containing what they found, why it might matter, evidence, ancestry, uncertainty and possible tests. Jane alone chooses what to investigate and learn; the hive never writes to Jane's retained memory.** No agent urgency, ranking, repetition, or vote can override Jane's choice.

## Local reproducible experiment
- 24/24 local Python regression tests PASS.
- A frozen deterministic interest policy (language=2, biology=1, math=0) faced 3 synthetic packets: language urgency 0, biology urgency 999, math urgency 1000.
- Selection 1: language, not the highest urgency.
- Simulated negative feedback reduced language interest by 2.
- Selection 2: biology, demonstrating policy change after feedback.
- Separate memory gates: packet presentation does NOT write memory, selection does NOT write memory, and even successful feedback does NOT write memory. Retain requires verification AND a distinct Jane-owned choice.
- Jane can emit a question independently of scouts; the example text was given to the method, **not generated by an autonomous model**.
- Missing evidence/ancestry, excessive cost, unknown/zero-interest topics permit abstention.
- The 24 tests check these mechanics, not genuine self-generated preferences.

## Critical boundary
Interest weights, case selection, reflection signals, and self-originated question example are **scripted test fixtures**. Changing an interest score under predetermined feedback is not proof Jane has originated values or autonomous curiosity.

## Next natural invariant — JANE 090: Interest Genesis
Can Jane choose a previously zero-interest topic because investigation is expected to resolve a *self-identified* gap, rather than because an agent set its priority? Test explicit exploration budget, blinded independent evaluator, no forced retention, and zero-packet/self-originated choice.
