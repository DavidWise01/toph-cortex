# JANE 078 — FLAY

Canonical carrier: `{{ 1x5ux1x5dx1x5lx1x5rx1 , repeat until satisfied }}`.

U/North/semantic = what it is, initial letter anchors concept (apple is a fruit, red sometimes, starts with A). D/South/somatic = context-dependent implied social relationships ("king implies status" in a particular social order; not universal value judgments). L/West/abstractive = surprising "what if?" question; explicitly hypothetical unless externally verified. R/East/holographic = like-for-like or family resemblance (pug and dachshund are dogs).

Each of four cardinal lanes has five distinction positions. One FLAY traverses U→D→L→R and repeats until purpose complete or all 20 positions are filled. A release snapshots prior data, computes SHA-256 content digest, and replaces the mutable batch while preserving the past.

**Boundary**: The model stores supplied statements and proposes the *first supplied west-lane question*. It does not autonomously infer meaning, verify LIT status, or choose topics without external input. The HTML demo is offline and session-local.

Run `python -S -m unittest -q test_model.py` to execute the 24 checks. Run `python -S model.py` for the example. The HTML works as a standalone teaching interface.
