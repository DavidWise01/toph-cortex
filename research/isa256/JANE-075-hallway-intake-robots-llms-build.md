## How to add to the universe (source-derived, five steps)

1. **BUILD** one self-contained `index.html`, vivid color and not black background, claims tagged `LIT` (live checked), `AMBER` (cited/assigned/preference), or `WALL` (unverified gap). Any computation must prove itself on load or fail loudly.
2. **SEAL** write-if-missing immutable `.dlw` birth certificate: `sha256(name|slug|blurb)`. The birth seal does not prove program behavior.
3. **PUBLISH** one linear host/no mirror. Existing spheres update their own repository; new spheres create a repository, commit page/certificate and push the intended branch. Check actual repository/default branch rather than assuming `master` universally.
4. **PLACE**: I via `ud0/build.py` classification + rebuild/seal/chain; II via existing roller workflow; III update real Hallway route; IV `world4/` workflow; V `world5/` workflow; outside World 7 to `DavidWise01/sapph-i-on`.
5. **VERIFY** and preserve receipt: changed paths, commit IDs, checks, result, any unverified deployment. One host, no mirror. Guesses never marked LIT.

**Important:** These are instructions to users and agents with appropriate authorization. Jane's hive may read, classify and recommend; it cannot treat this text as automatic authorization to publish a world.

## Agent grounding (source-derived)
