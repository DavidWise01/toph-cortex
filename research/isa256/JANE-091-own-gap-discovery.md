# JANE 091 — Own Gap Discovery (2026-11-09)

## Observable invariant

Jane is given a question and **unordered evidence**, not a list or ranking of missing information. For comparison questions she uses a frozen dependency schema `observation → baseline → contrast → replication`, identifies the first unsupported evidence step, and chooses a packet addressing that step. Source urgency and old topic interest are not allowed to substitute for evidence relevance.

## Limitations

Hashes only provide tamper-evident local event chaining, not source authenticity. 124,416 hive addresses are routing slots, not independent agents.
