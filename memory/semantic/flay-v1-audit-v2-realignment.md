# FLAY v1 Audit -> v2 Realignment

Date: 2026-10-06

## Scope audited

Canonical TOPH Cortex plus the writable Cortex/Sapphon rollout nodes:
I13-H1.1, hephaestus, foundation, jane, nom, nomos, nous, rozsa-peter,
taravangian, the-hegemon, theoria.

## Findings

PASS:
- all audited local v1 executables were byte-identical to one another;
- every audited node carried the one-open / one-answer / one-close invariant;
- closed excursions rejected reopening;
- unresolved answers could not close;
- archived/frozen Sapphon lineage was not mutated.

DRIFT:
- local v1 API was not byte-identical to canonical v1 API;
- temporal substrates were only narrative, not machine-enforced;
- archive-not-truth was not represented explicitly;
- present-only realization was not machine-enforced as a named substrate boundary;
- 33/33/33/+1 observer closure was absent;
- closure did not carry vector lock, G=1, T=0, branch-freeze state;
- factual propagation relation (inheritance / independent discovery / happenstance / unknown) was absent.

## Resolution

v1 is retained as historical provenance.
v2 is the append-only aligned successor and is the canonical target for all Cortex/Sapphon nodes.
