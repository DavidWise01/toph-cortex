# HJC-014 — Temporal Revolving Door

ROOT0 · .dlw · 2026-11-27

Canonical user correction:
{{ a, present ; lives | b, future ; writes | c, past ; reads }}

A completes in real time what B wrote would happen and C read would happen.

Proposed operational interpretation: B writes an immutable prospective record; C reads that exact record and retains its identity; A lives the actual transition and records the outcome. Completion records bind the original proposal, read observation and actual outcome. A mismatch remains evidence, not an excuse to rewrite the proposal. Logical causality for one transaction is WRITE -> READ -> LIVE -> APPEND. This is not backward physical causation or proof of prediction. Distinct functional roles do not require distinct physical substrates. The revolving door repeats for subsequent transactions while the shared referent remains singular. Existing ABCBCACABABC sequence is retained as a separate peripheral schedule; no claim that every adjacent edge is a transaction dependency.

This correction supersedes the static temporal-role interpretation for future HJC development without editing earlier freezes. Source specification only; runtime implementation and qualification pending.
