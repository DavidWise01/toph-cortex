Mathematical boundary

Q_ij(t) = probability that the next transition from state i enters j by time t. p_ij = Q_ij(∞). With absorbing exits, Σ_j p_ij + p_i,exit = 1. For transient transition matrix P, N = (I−P)⁻¹ exists when its spectral radius is less than one.

Invariant: surviving transient probability + cumulative absorbed probability = 1. A regeneration event requires a restart state that makes future dynamics independent of the prior path, conditioned on the reset state. Mere physical return does not imply renewal.
